# API gateways compared: Kong, Apigee, Tyk, Zuplo, Gravitee

_Last reviewed: 2026-09-01._

This page compares five API gateways and management platforms: the reverse proxy layer that sits in front of your services and applies authentication, rate limiting, transformation, and analytics, plus the control plane and developer portal that come with it. Facts were checked against each vendor's docs, pricing page, or GitHub repository on the review date. Out of scope: Kubernetes ingress controllers without an API management layer (NGINX Ingress, Envoy by itself), service meshes, cloud-provider-native gateways (AWS API Gateway, Azure APIM), and pure LLM routers that do not proxy ordinary HTTP APIs.

## Tool notes

**Apigee** is best at enterprise API programs that already run on Google Cloud and need analytics, monetization, API hub cataloging, and a security add-on from one vendor, and its MCP proxy needs no code beyond an OpenAPI file. The limitation is cost and lock-in: there is no open-source runtime, the policy language is XML, and PAYG bills both per call and per environment-hour.

**Gravitee** is best when you want one Apache-2.0 control plane for HTTP, event, and now agent traffic (MCP, A2A, LLM) with a bundled portal, at a flat per-gateway price rather than per call. The limitation is that the headline MCP Tool Server is Enterprise Edition, so the community build gives you the gateway and portal but not OpenAPI-to-MCP conversion.

**Kong** is best as the most widely deployed Apache-2.0 gateway with a mature Lua plugin ecosystem, declarative decK config, and a Konnect control plane that can manage data planes anywhere. The limitation is that the AI and MCP plugins that turn REST into MCP tools are Enterprise-only, so OSS users get the proxy but not the conversion layer.

**Tyk** is best for teams that want the MCP gateway itself (per-tool rate limits, filtered discovery, OAuth 2.1 protected-resource metadata) in an MPL-2.0 binary written in Go, with Tyk OAS as the single config format. The limitation is that the pieces most teams also want (Dashboard, Developer Portal, AI Studio Enterprise Edition) are licensed, and Tyk does not publish list prices.

**Zuplo** is best for API-first teams who want the gateway config to live in git as OpenAPI plus TypeScript and deploy to a global edge in seconds, with MCP and a portal included at $0 for 100K requests. The limitation is that the runtime is closed source, self-hosting is Kubernetes-only, and Builder pricing scales steeply ($100 per extra 100K requests) before Enterprise.

## How to choose

- You are on Google Cloud with an existing enterprise contract and an API hub catalog: pick Apigee because MCP proxies register in API hub automatically and reuse your existing policies.
- You need an open-source gateway you can run without any commercial license and you can live without a portal: pick Kong Gateway (Apache-2.0) or Tyk Gateway (MPL-2.0); pick Tyk if MCP proxying with per-tool rate limits must also be in the free binary.
- You want REST-to-MCP conversion in the gateway and prefer a managed edge with a free tier: pick Zuplo because the MCP Server handler and Zudoku portal are included on the $0 plan.
- You want a self-hosted, open-core platform with a bundled developer portal and predictable flat pricing: pick Gravitee because pricing is per production gateway with unlimited calls.
- You are a large enterprise that wants MCP, LLM routing, prompt guards, and OAuth for agents from one vendor with a SaaS control plane: pick Kong Konnect with AI Gateway Enterprise or Apigee, then compare the per-request versus per-gateway bills against your traffic.
- You need to govern existing remote MCP servers (not convert REST) in your own Kubernetes today: pick Tyk Gateway 5.13+ or Gravitee 4.10+ MCP Proxy; both are self-hostable.

## FAQ

### Which API gateway is open source?

Kong Gateway is Apache-2.0, Tyk Gateway is MPL-2.0 (with a proprietary `ee` directory in the same repository), and Gravitee API Management is Apache-2.0 with Enterprise Edition features gated by a license file. Apigee has no open-source runtime; only its optional Drupal-based portal is open source. Zuplo's gateway runtime is closed source, although its Zudoku developer portal framework is MIT.

### Which API gateway can expose an API as an MCP server?

All five can, with different gating. Zuplo's MCP Server handler takes OpenAPI operation IDs and is included on every plan including Free. Kong's AI MCP Proxy plugin (`conversion-listener` and `conversion-only` modes, Kong Gateway 3.12+) is Enterprise-only. Gravitee's MCP Tool Server (MCP entrypoint on a v4 proxy API) is Enterprise Edition, Tyk's REST-to-MCP conversion is a standalone npm CLI rather than a gateway feature, and Apigee's MCP proxy has been generally available since 2026-03-31.

### Do I need an API gateway for MCP?

No. An MCP server is a process or HTTP endpoint you can run directly, and a gateway is optional. A gateway becomes useful when you need centralized OAuth, per-tool rate limits, audit logs, and a catalog across many MCP servers, or when you want to turn an existing REST API into tools without writing server code. If you have one server and one client, publish the server directly and skip the gateway.

### Kong vs Apigee: which should I choose?

Choose Kong when you want an Apache-2.0 runtime you can self-host anywhere, a Lua/Go/JavaScript plugin model, and declarative decK configuration, with Konnect as an optional SaaS control plane. Choose Apigee when your organization already runs on Google Cloud, wants a fully managed runtime with API hub, analytics, and monetization included, and accepts XML policies and per-call plus per-environment-hour billing. Both put REST-to-MCP conversion behind their enterprise offerings.

### Which gateways bill per request and which bill per gateway?

Zuplo bills per request (100K free, then $100 per 100K on Builder). Apigee Pay-as-you-go bills per million calls by proxy type plus per environment-hour. Kong Konnect Plus bills per gateway per month with 1M requests included and $200 per extra million. Gravitee bills a flat rate per production gateway with unlimited calls, and Tyk's Professional plan is a flat price with unlimited requests.

### Which gateway includes a developer portal at no extra cost?

Zuplo includes its Zudoku portal on every plan including Free, and Gravitee ships the Developer Portal in the community build. Kong's Dev Portal is a Konnect feature (2 portals on Plus, unlimited on Enterprise) and is not in the OSS gateway. Tyk's Developer Portal is a licensed component in paid plans, and Apigee's integrated portal comes with a paid Apigee organization.

### Can I self-host all of these?

Kong, Tyk, and Gravitee run on your own Docker or Kubernetes with their open-source builds. Zuplo Self-Hosted runs only on Kubernetes and is a commercial option rather than an open-source download. Apigee hybrid runs the runtime plane on your Kubernetes cluster, but the management plane stays in Google Cloud, so it is self-hosted only for the data path.
