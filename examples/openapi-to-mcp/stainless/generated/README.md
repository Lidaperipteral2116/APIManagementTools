# generated/ (intentionally empty)

Nothing generated by Stainless is checked in here, and nothing was fabricated
to stand in for it.

Why it is absent: Stainless generation runs on Stainless's servers. `stl
preview` and `stl builds create` need `stl auth login` (an account), and the
free plan is capped at 25 endpoints per generator while `specs/demo-api.yaml`
has 29 operations (see the pricing note in ../README.md). Neither condition
held when this example was written, so there is no honest output to show.

What a maintainer with an account should paste here, after running the steps
in ../README.md:

1. The TypeScript SDK's `packages/mcp-server/` directory as Stainless produced
   it (`package.json`, `src/`, `README.md`). Leave out `node_modules/`,
   `dist/` and anything containing a token.
2. The `.stainless/workspace.json` that `stl init` wrote, with the project
   name and any org identifiers replaced by placeholders.
3. A `TOOLS.md` containing the tool list the server advertised, captured with
   `npx -y @modelcontextprotocol/inspector@2.4.0 --cli npx -y parcelio-mcp
   --code-execution-mode=local --method tools/list` (or the equivalent
   Inspector UI screenshot in ../images/). Expected per the Stainless MCP
   guide: a code-execution tool and a docs-search tool, not 28 endpoint tools.
4. The trimmed terminal output of `stl preview`, so the "Expected output"
   section of ../README.md can be filled in with something real.

Until then, ../README.md marks its "Expected output" as not captured.
